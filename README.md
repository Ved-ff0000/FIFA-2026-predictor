# FIFA World Cup 2026 Predictor ⚽

Machine Learning project that predicts match outcomes using historical FIFA match data.

## Features
- Match outcome prediction
- Probability visualization
- Streamlit dashboard
- Random Forest classifier

## Tech Stack
- Python
- Pandas
- Scikit-Learn
- Streamlit
- Matplotlib

## Run Locally

pip install -r requirements.txt

python model.py

streamlit run app.py
